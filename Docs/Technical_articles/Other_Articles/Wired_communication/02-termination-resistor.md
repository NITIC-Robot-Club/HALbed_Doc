# CANの終端抵抗の役割

CAN通信では、CAN_H と CAN_L の2本の線を使って信号を送ります。

この2本の線は、ただ電圧をかけているだけではなく、信号が「波」のようにケーブルの中を進んでいきます。  
そのため、ケーブルの端まで信号が届いたとき、端で信号が跳ね返ってしまうことがあります。

この跳ね返りを抑えるために使うのが、**終端抵抗**です。

## 終端抵抗とは

終端抵抗は、CANの通信線の両端につける抵抗です。

一般的なCANでは、次のように接続します。

- CAN_H と CAN_L の間に入れる
- 抵抗値は 120Ω
- バスの両端に1個ずつ入れる
- 合計で2個使う

つまり、CANバス全体では次のようになります。

CANノード --- CANノード --- CANノード  
↑　　　　　　　　　　　　　↑  
120Ω　　　　　　　　　　　120Ω

終端抵抗は、各基板に毎回つけるものではありません。  
**CANの配線全体を見たときの両端**につけます。

## なぜ必要なのか

CANの信号は、ケーブルの中を波のように進みます。

ケーブルの端に何もないと、信号がそこで反射して戻ってきます。  
反射した信号が元の信号と重なると、波形が乱れます。

波形が乱れると、マイコンやCANトランシーバが

「これは1なのか、0なのか」

を正しく判断できなくなることがあります。

終端抵抗は、この反射を吸収して、信号の波形を安定させる役割を持っています。

## 水と水路で考える

電気の信号を「水の波」、CANのケーブルを「水路」として考えてみます。

水路に波を送ると、波は水路の先へ進んでいきます。  
しかし、水路の端が壁になっていると、波は壁で跳ね返って戻ってきます。

この戻ってきた波が、新しく送った波とぶつかると、水面がぐちゃぐちゃになります。

CANでもこれと同じようなことが起こります。

- 電気信号 → 水の波
- CANケーブル → 水路
- ケーブルの端 → 水路の終わり
- 信号の反射 → 波の跳ね返り
- 終端抵抗 → 波を吸収する場所

終端抵抗は、水路の端にある「波を吸収する場所」のようなものです。  
波をその場で吸収して、跳ね返りを少なくします。

その結果、CANの信号がきれいに伝わりやすくなります。

## 終端抵抗がないとどうなるか

終端抵抗がない場合、通信がまったくできないとは限りません。  
短い配線や低速通信では、たまたま動くこともあります。

しかし、次のような問題が起きやすくなります。

- 通信が不安定になる
- たまにデータが化ける
- エラーフレームが増える
- 配線を長くすると通信できなくなる
- 通信速度を上げると失敗しやすくなる

「動いたから大丈夫」とは限らないのが注意点です。

## 終端抵抗が多すぎてもよくない

終端抵抗は、基本的に2個です。

もし3個以上つけると、CAN_H と CAN_L の間の抵抗値が小さくなりすぎます。  
すると、CANトランシーバに流れる電流が増え、信号の電圧差が小さくなることがあります。

その結果、これも通信不良の原因になります。

## 確認方法

電源を切った状態で、CAN_H と CAN_L の間の抵抗をテスターで測ると確認できます。

正しく120Ωの終端抵抗が2個入っている場合、並列になるため、だいたい60Ωになります。

目安は次の通りです。

- 約60Ω：終端抵抗が2個入っている
- 約120Ω：終端抵抗が1個しかない
- かなり大きい値：終端抵抗が入っていない
- 60Ωよりかなり小さい：終端抵抗が多すぎる可能性がある

## まとめ

CANの終端抵抗は、信号の反射を抑えるための抵抗です。

CANの信号はケーブルの中を波のように進むため、端で反射すると波形が乱れます。  
終端抵抗を両端に入れることで、反射を抑えて通信を安定させます。

基本は、CANバスの両端に120Ωを1個ずつです。  
全体で2個入っていれば、CAN_H と CAN_L の間は約60Ωになります。
