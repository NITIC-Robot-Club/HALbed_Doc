# センサー選定

ロボットで何を知りたいかによって、候補となるセンサーは変わります。このページでは、添付資料の分類をもとに、センサーの候補を順に選べます。

最初の分岐は「内部」「外部」「回路」です。「内部」では速度や位置、「外部」では距離・位置や色、「回路」では電源の状態を基準に選びます。全体表示では、この3つの枝とその先をひとつのツリーとして確認できます。

<SensorSelector />

## 使い方

1. 「内部」「外部」「回路」のいずれかを選びます。
2. 表示されたツリー全体から、知りたい量や対象に近いノードを選びます。
3. 選択したノードが中央へ移動し、親の分岐・次の候補・上下のつながりが確認できます。
4. 末端のセンサー名と、選択経路・用途の説明を確認します。「選定画面に戻る」では経路に絞った表示へ戻れます。

ここで表示する説明は、センサーの一般的な用途を示すものです。実際の採用時は、必要な測定範囲、精度、応答速度、取り付け条件、インターフェースなどを製品仕様で確認してください。
