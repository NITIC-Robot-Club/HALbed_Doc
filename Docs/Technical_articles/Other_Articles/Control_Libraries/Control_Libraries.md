# 制御ライブラリ

コントローラーや受信機から届く操作入力を、STM32のアプリケーションで扱うためのライブラリをまとめています。

## ライブラリ一覧

- [PS3-S.B.D.B.T.受信ライブラリ](./PS3_sbdbt_cube_lib)
- [T10J S.BUS受信ライブラリ](./T10J_SBUS_cube_lib)

## 選び方

| 使いたい入力機器 | ライブラリ | 主な接続方式 |
|---|---|---|
| PS3コントローラーとSBDBT受信機 | PS3-S.B.D.B.T.受信ライブラリ | UART 115200 baud、8N1 |
| Futaba T10JとS.BUS対応受信機 | T10J S.BUS受信ライブラリ | S.BUS、UART受信 |

どちらも入力値を取得した後のモーター制御や機体制御は行いません。受信状態を確認し、アプリケーション側で安全な範囲に変換してから利用してください。
