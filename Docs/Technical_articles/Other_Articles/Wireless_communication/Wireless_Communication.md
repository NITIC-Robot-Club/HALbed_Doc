# 無線通信の基本

日常生活では、Wi-FiやBluetooth、スマートフォンの4G/5Gなどが無線通信です。無線通信と意識することは少ないかもしれません。

ここでは、その無線通信に注目して、無線の基本からロボコンで使う無線までを紹介します。

## 無線通信は、どこで使われている？

スマートフォンは基地局と電波で通信し、イヤホンはBluetoothでスマートフォンとつながっています。家の中では、Wi-FiがPCやゲーム機をネットワークへ接続します。

どれもケーブルをつないでいないのに、データが届きます。

一方で、無線通信は目に見えません。ケーブルが抜ければ原因に気づきやすい有線通信と違い、無線では「なぜ届かないのか」が分かりにくいことがあります。

## ロボットでは、無線通信を選ぶ

日常生活の機器では、使う無線方式が最初から決まっていることが多いものです。ロボット製作では、操縦信号、センサーの値、ログ、カメラ映像などを、どの無線で送るか自分たちで決める場合があります。

たとえば、次の通信は必要な性能がそれぞれ違います。

- 操縦信号：短いデータを、できるだけ遅れずに送りたい
- センサー値：少ないデータを、安定して送りたい
- カメラ映像：大量のデータを、連続して送りたい
- 設定やログ取得：速度より、接続しやすさや確実さを重視したい

すべてを同じ無線で解決できるとは限りません。必要な通信が違えば、向いている方式も変わります。

## 無線は、使う環境で状態が変わる

同じ機器でも、置く場所や周囲の機器が変わると通信状態が変わります。壁や人で電波が弱くなったり、金属で反射したり、別の無線機器と電波が重なったりするからです。

では、無線の何が通信状態を変えるのでしょうか。

まず、電波の周波数と波長を見ます。次に、距離による減衰、遮蔽物、反射、回折、アンテナ、干渉という性質を見ます。そのうえで、Wi-Fiやプロポなどを、ロボットの用途と結びつけます。
