# 無線通信の基本

日常生活では、Wi-FiやBluetooth、スマートフォンの4G/5Gなどが無線通信です。無線通信と意識することは少ないかもしれません。

ここでは、その無線通信に注目して、無線の基本からロボコンで使うちょっと変わった無線まで紹介します。

## 無線通信は、どこで使われている？

スマートフォンは、基地局と電波で通信しています。イヤホンは、Bluetoothでスマートフォンとつながっています。家の中では、Wi-FiがPCやゲーム機をネットワークへ接続します。

どれもケーブルをつないでいないのに、データが届きます。

しかし、無線通信は目に見えません。ケーブルが抜ければ原因に気づきやすい有線通信と違い、無線では「なぜ届かないのか」が分かりにくいことがあります。

## ロボットでは、無線通信を自分で考える

日常生活の機器では、使う無線方式が最初から決まっていることが多いものです。スマートフォンは対応する携帯電話網を使い、イヤホンは対応するBluetoothで接続します。

ロボット製作では、操縦信号、センサーの値、ログ、カメラ映像などを、どの無線で送るか自分たちで決める場合があります。

たとえば、次のような違いがあります。

- 操縦信号は、短いデータをできるだけ遅れずに送りたい
- センサー値は、少ないデータを長い距離へ送りたい
- カメラ映像は、大量のデータを連続して送りたい
- 設定やログ取得は、速度より接続しやすさを重視したい

すべてを同じ無線で解決できるとは限りません。必要な通信が違えば、向いている方式も変わります。

## 無線なら、どこでも同じように使える？

そうではありません。

家の中で使えるWi-Fiでも、金属の多い体育館や、多くのチームが無線を使う会場では通信が不安定になることがあります。壁や人で電波が弱くなったり、別の無線機器と電波が重なったりするからです。

では、無線の何が通信状態を変えるのでしょうか。

まず、電波の周波数と波長を見ます。次に、反射、透過、回折、干渉、減衰という電波の性質を見ます。そのうえで、Wi-Fiやプロポなどの通信方式を、ロボットの用途と結びつけます。

- Wi-Fi、Bluetooth、4G/5Gは、日常生活で使っている無線通信
