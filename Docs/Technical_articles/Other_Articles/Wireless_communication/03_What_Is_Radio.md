# 無線通信 3：電波とは

「2.4GHzと5GHzは何が違うのか」。無線を選び始めると、周波数の数字が気になります。

ただし、2.4GHzや5GHzは無線機の名前ではありません。主に使っている電波の周波数を表しています。

## 電波は情報を運ぶ波

電波は、空間を伝わる電磁波の一種です。送信機は電気信号を電波に変換し、受信機は受け取った電波から情報を取り出します。

```text
送信する情報 → 送信機 → 電波 → 受信機 → 取り出した情報
```

電波そのものに「Wi-Fi」や「Bluetooth」という文字が書かれているわけではありません。電波にどのような規則で情報を載せるかによって、通信方式が決まります。

## 周波数とは

周波数は、1秒間に波が振動する回数です。

- 1MHz = 1,000,000Hz
- 1GHz = 1,000,000,000Hz

たとえば2.4GHzは、1秒間に約24億回振動する周波数です。920MHzは、2.4GHzより低い周波数です。

周波数が違うと、波の長さや障害物への影響が変わります。そのため、通信に使う場所を決めるときに周波数が重要になります。

## 波長とは

波長は、波一つ分の長さです。電波の速さを `c`、周波数を `f`、波長を `λ` とすると、次の関係があります。

```text
λ = c / f
```

周波数が高いほど、波長は短くなります。

- 2.4GHz：約12.5cm
- 5GHz：約6cm
- 920MHz：約33cm

波長はアンテナの大きさや、障害物の端を回り込む性質に関係します。これが、周波数によって「届きやすさ」の傾向が変わる理由の一つです。

## 周波数帯の名前

実際の無線機は、ある一つの周波数だけで通信するとは限りません。一定の範囲を使うため、その範囲を「周波数帯」と呼びます。

| 呼び方 | 主な通信の例 |
|---|---|
| 2.4GHz帯 | Wi-Fi、Bluetooth、RCプロポ、Zigbee |
| 5GHz帯 | Wi-Fi |
| 6GHz帯 | Wi-Fi 6E、Wi-Fi 7 |
| 920MHz帯 | テレメトリ、センサー通信 |
| 429MHz帯 | 特定小電力のデータ通信 |
| 1216MHz帯 | 特定小電力のデータ通信 |

「2.4GHz帯を使う」と書いてあっても、2.4GHzぴったりの電波だけを使うとは限りません。通信方式ごとに、使える範囲やチャンネルが決まっています。

## 高い周波数なら速い？

必ずしもそうではありません。

通信速度には、周波数のほかに、次の要素が関係します。

- 一度に使える帯域幅
- 電波に情報を載せる変調方式
- 信号と雑音の比（SNR）
- 複数のアンテナを使うMIMO
- 通信プロトコルと再送方法

高い周波数帯は、広い帯域を確保しやすいことがあります。一方で、壁や人体などの影響を受けやすくなる傾向もあります。

速さと届きやすさは、同じ尺度ではありません。

## ロボットで考えると

ロボットの操縦では、映像ほど大きなデータを送らなくても、入力が遅れたり途切れたりすると操作しにくくなります。

逆に、映像では大量のデータを送りたいので、広い帯域幅が役に立ちます。ここで、同じ無線に「速さ」と「遅れにくさ」の両方を求めると、設計が難しくなります。

周波数は、用途を決める材料の一つです。用途そのものを決める数字ではありません。

## このページの要点

- 周波数は、1秒間に波が振動する回数
- 波長は、波一つ分の長さ
- 周波数が高いほど波長は短い
- 周波数帯の名前と通信方式の名前は別物
- 通信速度は周波数だけでは決まらない
