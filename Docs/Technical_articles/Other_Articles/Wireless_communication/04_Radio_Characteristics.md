# 無線通信 4：電波の伝わり方

ロボットを少し動かしただけで、無線の状態が変わることがあります。

送信機と受信機が同じものでも、机の上では通信できたのに、体育館でロボットを走らせると途切れる。これは、電波が送信機から受信機まで単純にまっすぐ届いているわけではないからです。

電波の強さは、周波数、距離、障害物、アンテナの向き、周囲の無線機器によって変わります。

## 周波数と波長

周波数は、1秒間に波が振動する回数です。波長は、波一つ分の長さです。

電波の速さを `c`、周波数を `f`、波長を `λ` とすると、次の関係があります。

```text
λ = c / f
```

周波数が高いほど波長は短くなります。

| 周波数の例 | 波長の目安 |
|---|---:|
| 429MHz | 約70cm |
| 920MHz | 約33cm |
| 2.4GHz | 約12.5cm |
| 5GHz | 約6cm |
| 6GHz | 約5cm |

波長は、障害物の端を回り込む性質や、アンテナの大きさに関係します。ただし、周波数が高いほど通信速度が速い、という意味ではありません。

## 距離による減衰

送信機から離れるほど、電波は広い範囲へ広がります。そのため、受信機で受け取れる電波は弱くなります。このように、距離によって電波が弱くなることを距離による減衰と考えます。

見通しのよい理想的な空間でも、距離が伸びれば受信信号は弱くなります。実際の会場では、壁や床からの反射、人による遮蔽、アンテナの向きも重なるため、単純に距離だけでは通信距離を予測できません。

「最大通信距離が100m」と書かれた機器でも、金属の多い体育館や人の多い会場で同じ距離まで通信できるとは限りません。最大距離は、測定条件と一緒に読みます。

## 遮蔽物：通り抜けても弱くなる

電波は、壁や人体などを通り抜けることもあります。しかし、通り抜けるときには弱くなります。この弱くなることを減衰と呼びます。

減衰の大きさは、物体の材質、厚さ、水分量、電波の周波数などで変わります。金属は電波を遮りやすく、人体も水分を含むため電波に影響します。

5GHzや6GHzは、2.4GHzより遮蔽物の影響を受けやすい傾向があります。高い周波数のWi-Fiが速く通信できても、壁越しの到達性まで高いとは限りません。

## 反射とマルチパス

電波が金属やコンクリートなどに当たると、跳ね返ることがあります。これが反射です。

受信機には、送信機から直接届く電波と、壁や床で反射してから届く電波が同時に届くことがあります。このように、複数の経路を通った電波が受信機へ届く状態をマルチパスと呼びます。

二つの波が強め合えば受信しやすくなり、弱め合えば受信しにくくなります。そのため、アンテナやロボットの位置を数cm変えただけで、通信状態が変わる場合があります。

体育館の壁や床、ロボットの金属フレームは、電波を反射する面になります。通信が場所によって急に良くなったり悪くなったりするときは、マルチパスも原因の候補です。

## 回折：障害物の端を回り込む

電波は、障害物の端を回り込むことがあります。これが回折です。

波長が長い電波ほど、障害物の端を回り込みやすい傾向があります。そのため、低い周波数の電波は、見通しが悪い場所で比較的有利になることがあります。

ただし、回折しても電波は弱くなります。低い周波数ならどこでも届く、という意味ではありません。

## アンテナの向きと偏波

アンテナは、どの方向に置いても同じように電波を送受信できるとは限りません。

棒状のアンテナには、電波の電界が振動する向き、つまり偏波があります。送信側と受信側のアンテナの向きがそろっていると受信しやすく、向きが大きくずれると受信しにくくなることがあります。

たとえば、垂直に置いたアンテナと水平に置いたアンテナでは、条件によって受信状態が悪くなります。ロボットが旋回するなら、アンテナの向きも変化します。

アンテナを金属板の裏に隠す、電池やモーターの近くに置く、ケーブルを強く曲げるといった配置も、通信状態に影響します。無線モジュールの性能だけでなく、アンテナをどこに置くかまでが通信設計です。

## 干渉：他の機器と電波が重なる

近くの無線機器が同じ周波数帯で送信すると、目的の信号が読み取りにくくなることがあります。これが干渉です。

干渉の影響は、周波数が同じかどうかだけでは決まりません。

- 送信出力がどのくらいか
- アンテナがどこを向いているか
- 使っている帯域幅がどのくらいか
- 送信する時間が重なっているか
- 周波数を切り替える方式か
- 失敗したデータを再送するか

同じ2.4GHz帯でも、Wi-Fi、Bluetooth、RCプロポは通信の仕組みが違います。そのため、混雑したときの影響も同じではありません。

## 体育館で原因を切り分ける

通信が途切れたとき、すぐに「無線モジュールが悪い」とは限りません。次の条件を一つずつ変えると、原因を切り分けやすくなります。

1. 送信機と受信機の距離を変える
2. 人や金属板を間に置いて変化を見る
3. ロボットの向きとアンテナの向きを変える
4. 周囲のWi-Fiやプロポを増減させる
5. 通信量を減らし、映像などの大容量通信を止めて比べる

机の上でつながるかだけでなく、ロボットを動かした状態で試験することが重要です。

## このページの要点

- 周波数が高いほど波長は短くなる
- 電波は距離が伸びるほど弱くなる
- 遮蔽物を通り抜けても、電波は減衰する
- 反射した電波が複数経路で届くと、マルチパスが起こる
- 回折によって障害物の端を回り込むことがある
- アンテナの向きと偏波をそろえることが重要
- 他の機器との干渉は、周波数だけでなく通信方式や帯域幅にも左右される
