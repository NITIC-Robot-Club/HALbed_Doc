# 無線通信 4：電波の伝わり方

無線通信が不安定になったとき、まず「電波が弱い」と考えたくなります。しかし、電波の状態を変えるのは距離だけではありません。

壁や人体で弱くなることもあれば、金属で反射することもあります。複数の経路から届いた電波が重なることもあります。アンテナの向きや、近くで使われる別の無線機器も関係します。

このページでは、電波が送信機から受信機へ届くまでに起こることを、順番に見ていきます。

## 周波数と波長

周波数は、1秒間に波が振動する回数です。波長は、波一つ分の長さです。

電波の速さを `c`、周波数を `f`、波長を `λ` とすると、次の関係があります。

```text
λ = c / f
```

周波数が高いほど、波長は短くなります。

| 周波数の例 | 波長の目安 |
|---|---:|
| 429MHz | 約70cm |
| 920MHz | 約33cm |
| 2.4GHz | 約12.5cm |
| 5GHz | 約6cm |
| 6GHz | 約5cm |

波長は、障害物の端を回り込む性質や、アンテナの大きさに関係します。ただし、周波数が高いほど通信速度が速い、という意味ではありません。

## 距離による減衰

送信機から離れるほど、電波は広い範囲へ広がります。そのため、受信機で受け取れる電波は弱くなります。このように、距離によって電波が弱くなることを減衰と考えます。

見通しのよい理想的な空間でも、距離が伸びれば受信信号は弱くなります。実際には、壁や床からの反射、人による遮蔽、アンテナの向きなども重なるため、通信距離を距離だけで予測することはできません。

「最大通信距離が100m」と書かれた機器でも、測定条件と同じように使えるとは限りません。最大距離は、見通し、送信出力、アンテナ、通信速度などの条件と一緒に読みます。

## 遮蔽物：通り抜けても弱くなる

電波は、壁や人体などを通り抜けることもあります。しかし、通り抜けるときには弱くなります。この弱くなることも減衰です。

減衰の大きさは、物体の材質、厚さ、水分量、電波の周波数などで変わります。金属は電波を遮りやすく、人体も水分を含むため電波に影響します。

5GHzや6GHzは、2.4GHzより遮蔽物の影響を受けやすい傾向があります。高い周波数のWi-Fiが速く通信できても、壁越しの到達性まで高いとは限りません。

## 反射とマルチパス

電波が金属やコンクリートなどに当たると、跳ね返ることがあります。これが反射です。

受信機には、送信機から直接届く電波と、壁や床などで反射してから届く電波が同時に届くことがあります。このように、複数の経路を通った電波が受信機へ届く状態をマルチパスと呼びます。

二つの波が強め合えば受信しやすくなり、弱め合えば受信しにくくなります。そのため、アンテナや受信機の位置を少し変えただけで、通信状態が変わる場合があります。

ただし、マルチパスは悪いことばかりではありません。屋内のWi-Fiでは、直接届く電波だけでなく反射波も届くマルチパス伝搬が普通に起こります。OFDMやMIMOを使うWi-Fiは、このような環境をある程度前提にして設計されています。複数の経路から届く信号を処理したり、複数のアンテナで得た情報を組み合わせたりすることで、反射を含む環境でも通信しやすくできます。

問題になるのは、反射した電波の時間差が大きすぎる場合や、人やロボットの移動によって経路が急に変化する場合です。そのときは、信号の一部が重なって誤りが増えたり、受信状態が短時間で変化したりします。

反射する物体が多い環境でも、マルチパスを一律に「悪いもの」と決めつける必要はありません。通信方式がどのような環境を想定しているか、時間差や環境変化がどの程度あるかを分けて考えます。

## 回折：障害物の端を回り込む

電波は、障害物の端を回り込むことがあります。これが回折です。

波長が長い電波ほど、障害物の端を回り込みやすい傾向があります。そのため、低い周波数の電波は、見通しが悪い場所で比較的有利になることがあります。

ただし、回折しても電波は弱くなります。低い周波数なら、どこでも届くという意味ではありません。

## アンテナの向きと偏波

アンテナは、どの方向に置いても同じように電波を送受信できるとは限りません。

棒状のアンテナには、電波の電界が振動する向き、つまり偏波があります。送信側と受信側のアンテナの向きがそろっていると受信しやすく、向きが大きくずれると受信しにくくなることがあります。

たとえば、垂直に置いたアンテナと水平に置いたアンテナでは、条件によって受信状態が悪くなります。ロボットが旋回する場合は、アンテナの向きも変化します。

アンテナを金属板の裏に隠す、電池やモーターの近くに置く、ケーブルを強く曲げるといった配置も、通信状態に影響します。無線モジュールの性能だけでなく、アンテナをどこに置くかまでが通信設計です。

大きな金属フレームをアンテナのすぐ近くに置くと、電波の反射だけでなく、アンテナの特性や指向性にも影響することがあります。アンテナの周囲に金属を置かないことを基本にし、避けられない場合は、使用する波長を目安に距離を取って実機で確認します。

## 減衰と干渉を分けて考える

減衰と干渉は、どちらも通信を不安定にしますが、原因は別です。

- **減衰**：距離や壁などによって、目的の電波そのものが弱くなる
- **干渉**：別の無線機器の電波が重なり、目的の信号を読み取りにくくなる

同じ周波数帯の機器が多い場所で起きる混信は、減衰よりも干渉が主な原因になることがあります。この場合、送信出力を上げるだけでは解決しません。チャンネル、通信方式、アンテナの配置、送信する時間を見直します。

一方で、周波数が高いほど距離や遮蔽物の影響を受けやすくなる傾向もあります。減衰と干渉を分けて考えると、「電波を強くすればよい問題」なのか「他の通信と分ける問題」なのかを判断しやすくなります。

## 干渉：他の機器と電波が重なる

近くの無線機器が同じ周波数帯で送信すると、目的の信号が読み取りにくくなることがあります。これが干渉です。

干渉の影響は、周波数が同じかどうかだけでは決まりません。

- 送信出力がどのくらいか
- アンテナがどこを向いているか
- 使っている帯域幅がどのくらいか
- 送信する時間が重なっているか
- 周波数を切り替える方式か
- 失敗したデータを再送するか

同じ2.4GHz帯でも、Wi-Fi、Bluetooth、RCプロポは通信の仕組みが違います。そのため、混雑したときの影響も同じではありません。

## 通信トラブルを切り分ける

通信が途切れたとき、すぐに「無線モジュールが悪い」とは限りません。条件を一つずつ変えると、原因を切り分けやすくなります。

1. 送信機と受信機の距離を変える
2. 人や金属板を間に置いて変化を見る
3. 受信機やアンテナの向きを変える
4. 周囲の無線機器を増減させる
5. 通信量を減らし、大容量データを止めて比べる
6. 機器を動かした状態でも同じ現象が起きるか確認する

「つながるか、つながらないか」だけでなく、遅延、パケットロス、再接続までの時間も記録すると、原因を考えやすくなります。

## このページの要点

- 周波数が高いほど波長は短くなる
- 電波は距離が伸びるほど弱くなる
- 遮蔽物を通り抜けても、電波は減衰する
- 反射した電波が複数経路で届くと、マルチパスが起こる
- マルチパスはWi-Fiで利用されることもあるが、時間差や環境変化が大きいと問題になる
- 回折によって障害物の端を回り込むことがある
- アンテナの向きと偏波をそろえることが重要
- 他の機器との干渉は、周波数だけでなく通信方式や帯域幅にも左右される
- 混信の原因が干渉なら、送信出力を上げるだけでは解決しない
