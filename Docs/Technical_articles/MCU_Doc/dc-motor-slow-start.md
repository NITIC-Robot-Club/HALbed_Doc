# DCモーターのスロースタート

DCモーターへ停止中から大きなPWMを与えると、モーターが急に動き出します。このとき、起動電流、タイヤの空転、ギアやベルトへの衝撃が大きくなることがあります。

スロースタートは、モーターへの指令値を一度に目標値へ変えず、一定時間をかけて近づける方法です。最初に試すなら、指令値の変化量を制限するレートリミッタが扱いやすい方法です。

## 指令値をゆっくり変える

例えば、PWMを次のように瞬間的に変えるとします。

```text
0% → 100%
```

スロースタートでは、現在の指令値を目標値へ少しずつ近づけます。

```text
0% → 10% → 20% → 30% → … → 100%
```

これにより、起動時の電流や機構への衝撃を小さくできる可能性があります。ただし、指令値を滑らかにしても、実際の速度が同じように変化するとは限りません。負荷、電源電圧、静止摩擦によってモーターの動きは変わります。

![モーター指令値の変化形状](./images/Low_Layer/motor-command-profiles.png)

## まず使うレートリミッタ

制御周期ごとに、指令値を一定量だけ増減させます。次の関数は、1秒あたりの変化量を指定する例です。

```c
float updateRamp(float current, float target,
                 float rate_per_second, float delta_time)
{
    float max_change = rate_per_second * delta_time;

    if (target > current) {
        current += max_change;
        if (current > target) {
            current = target;
        }
    }
    else if (target < current) {
        current -= max_change;
        if (current < target) {
            current = target;
        }
    }

    return current;
}
```

`current`と`target`は同じ単位で指定し、`delta_time`は秒で渡します。PWMを0.0〜1.0で扱う場合、次の例では1秒で0.0から1.0まで変化します。

```c
const float control_period = 0.01f;
const float output_rate = 1.0f;

motor_output = updateRamp(
    motor_output,
    target_output,
    output_rate,
    control_period
);
```

制御周期が10msなら、1回の最大変化量は`1.0 × 0.01 = 0.01`です。周期が変わっても実際の`delta_time`を渡せば、加速時間を同じ値に保ちやすくなります。

この処理は、指令値の変化率を制限するため、**レートリミッタ**と呼ばれます。減速にも同じ関数を使えます。

## ステップ入力と台形加減速

目標値をそのまま出力する方法は、**ステップ入力**です。

```c
motor_output = target_output;
```

指令値が一瞬で変化するため、モーターは大きなトルクを出そうとします。実際の速度は瞬間的には変わらないので、電流や機械的な負荷が大きくなります。

一方、レートリミッタで指令値を一定の割合で増減させると、速度指令のグラフは台形に近い形になります。このため、速度指令を計画する方法を**台形加減速**と呼ぶことがあります。

ただし、PWMのレートリミッタと、速度制御器へ与える台形速度指令は同じものではありません。前者は入力指令の変化量を制限し、後者は目標速度と加速度の軌道を決めます。

## 台形加減速でも振動が残る理由

台形加減速では、速度を直線的に変化させます。速度そのものは連続ですが、加速を始める瞬間には、加速度が0から一定値へ急に変化します。

![台形加減速とS字加減速の比較](./images/Low_Layer/trapezoid-vs-scurve-motion.png)

加速度の時間変化率を**ジャーク**と呼びます。

```text
ジャーク = 加速度の時間変化率
```

加速開始時や終了時のジャークが大きいと、重い物体、長いアーム、ベルト機構、バックラッシの大きいギアなどで振動として現れることがあります。低速の小型モーターでは問題にならない場合もあります。

## S字加減速

加速度を急に切り替えず、徐々に増減させる方法が**S字加減速**です。速度のグラフは、始めと終わりが丸くなったS字に近い形になります。

![S字を作る代表的な関数](./images/Low_Layer/s-curve-functions.png)

```text
台形加減速：速度は直線的、加速度は急に切り替わる
S字加減速：速度の始めと終わりが滑らか、加速度も変化する
```

S字加減速は、機械的な振動や衝撃を小さくしたい場合に有効です。ただし、S字にしたから必ず振動がなくなるわけではありません。機構の共振、制御器の設定、モーターのトルクも確認します。

## S字の指令値を作る方法

S字状の指令値は、シグモイド関数、cos補間、Smoothstepなどで作れます。ここでは、計算量と終了時刻の違いを押さえます。

### シグモイド関数

代表的なシグモイド関数がロジスティック関数です。

```text
f(t) = 1 / (1 + exp(-k(t - t0)))
```

`t`は時間、`t0`は曲線の中央となる時刻、`k`は曲線の急さです。`f(t)`に目標出力を掛けて使います。

```c
#include <math.h>

float sigmoid(float time, float center, float steepness)
{
    return 1.0f / (1.0f + expf(-steepness * (time - center)));
}
```

ただし、ロジスティック関数は有限時間で完全な0や1にはなりません。指定した時間で確実に目標値へ到達したい場合は、開始・終了時刻で正規化するか、終了時に目標値を直接代入します。

また、`expf()`はマイコンによっては計算負荷が大きくなります。短い制御周期や多数のモーターを扱う場合は、実行時間を測定します。

### cos補間

`t`を0〜1に正規化すると、cos関数で次の曲線を作れます。

```text
f(t) = (1 - cos(πt)) / 2
```

`t = 0`で0、`t = 1`で1になり、開始時と終了時の傾きが0になります。

```c
#include <math.h>

float smoothStepCos(float progress)
{
    if (progress <= 0.0f) return 0.0f;
    if (progress >= 1.0f) return 1.0f;

    return 0.5f - 0.5f * cosf((float)M_PI * progress);
}
```

経過時間から進行度を作り、目標出力へ掛けます。

```c
float progress = elapsed_time / ramp_time;
float ratio = smoothStepCos(progress);
motor_output = target_output * ratio;
```

### Smoothstep

Smoothstepは、三角関数や指数関数を使わずにS字を作る方法です。

```text
f(t) = 3t² - 2t³
```

```c
float smoothStep(float progress)
{
    if (progress <= 0.0f) return 0.0f;
    if (progress >= 1.0f) return 1.0f;

    return progress * progress * (3.0f - 2.0f * progress);
}
```

### 方式の比較

| 方式 | 特徴 | 計算量 | 向いている場面 |
|---|---|---:|---|
| ステップ入力 | すぐ目標値へ変える | 小 | 動作確認、急な応答が必要な場合 |
| レートリミッタ | 指令値の変化率を制限 | 小 | 最初のスロースタート |
| Smoothstep | 軽い計算でS字を作る | 小 | 指定時間で滑らかにつなぐ |
| cos補間 | 始めと終わりの傾きが0 | 中 | 滑らかな軌道を作る |
| シグモイド | 曲線の形を調整しやすい | 大 | 曲線形状を細かく調整する場合 |

## PWM指令と速度指令

スロースタートをどこへ入れるかで、制御の意味が変わります。

### PWMを徐々に増やす

```text
PWMデューティ比
0% → 100%
```

実装は簡単ですが、PWMと速度の関係は一定ではありません。負荷や電源電圧によって同じPWMでも速度が変わり、PWMが小さい間は静止摩擦に負けて回転しないことがあります。

### 速度指令を徐々に増やす

```text
目標速度
0 rpm → 1000 rpm
```

速度制御器へ渡す目標値を徐々に変化させます。エンコーダーを使ったフィードバック制御では、こちらの方が速度の軌道を設計しやすくなります。ただし、速度PIDの出力が飽和すると、設定した加速曲線どおりに動かないことがあります。

## 最小PWMを確認する

モーターには、PWMを少し与えただけでは回転しない領域があります。例えば0〜15%では停止し、16%を超えると動き始めるモーターです。

この場合、指令値を滑らかに増やしても、実際にはしばらく停止してから動き始めます。回転開始に必要な最小出力を測定し、必要なら補正します。

```c
float applyMinimumOutput(float output)
{
    const float minimum_output = 0.16f;

    if (output > 0.0f && output < minimum_output) {
        return minimum_output;
    }
    if (output < 0.0f && output > -minimum_output) {
        return -minimum_output;
    }
    return output;
}
```

最初から最小PWMを与えるため、小さな衝撃は残ります。速度センサーを使える場合は、PWM値だけでなく実速度を見ながら調整します。

## どの方法を選ぶか

単純に起動時の電流や衝撃を抑えたいなら、レートリミッタから始めます。

```text
まず動かしてみる              → レートリミッタ
レートリミッタで振動が残る    → Smoothstepまたはcos補間
速度の軌道を厳密に管理する    → 台形／S字の速度プロファイル
加速度やジャークも制限する    → ジャーク制限付きS字加減速
```

シグモイド関数を使うことだけがS字加減速ではありません。開始時と終了時を滑らかにつなぎ、機構と制御器の応答を確認することが重要です。

## まとめ

スロースタートは、モーターへの指令値を時間をかけて目標値へ近づける方法です。最初はレートリミッタで指令値の変化率を制限すると、加速時間を分かりやすく設定できます。

それでも振動が残る場合は、加速度の急な切り替え、つまりジャークに原因がある可能性があります。S字加減速では、加速度も徐々に変化させます。

PWMを滑らかにする方法と、速度指令を計画する方法は別物です。負荷、静止摩擦、制御器の飽和を確認し、実際の速度と電流を測りながら調整してください。
