## リファレンスの読み方

各ページには、APIの概要、初期化方法、使用例、制約をまとめています。先にSTM32CubeMXでクロック、ピン、割り込み、DMAなどを設定してください。HALbedはCubeMXが生成したHALハンドルを使います。

- 最初に[インストールと初期設定](../Introduction/GettingStarted.md)を済ませ、使うペリフェラルをCubeMXで有効にしてください。
- 関数とヘッダの対応は[HALbed関数一覧](./HALbed_Functions.md)にまとめています。
- HALbed APIとSTM32 HAL APIは別の層です。HALの説明は下記の資料を参照してください。
