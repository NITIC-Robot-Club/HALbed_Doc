# Flash HAL API

## 概要

内蔵Flashに設定値や保存データを書き込むと、電源を切った後も値を保持できます。RAMと違い、Flashは任意のバイトをそのまま上書きできません。書き込み前にページを消去し、MCUが対応する書き込み幅とアラインメントに合わせてデータを書き込みます。

ページサイズ、ページ番号、バンク構成、書き込み幅、実行中のコードからアクセスできる範囲はMCUによって異なります。このページではSTM32G4 HALの型と定数を使います。他のシリーズでは対象のHALヘッダとリファレンスマニュアルを確認してください。

## 関数概要

<ApiSignature :signature="'HAL_StatusTypeDef HAL_FLASH_Unlock(void);'" />

<ApiSignature :signature="'HAL_StatusTypeDef HAL_FLASH_Lock(void);'" />

Flash制御レジスタのロックを解除し、処理後に再びロックします。消去や書き込みに失敗した場合も、終了前にロックしてください。

<ApiSignature :signature="'HAL_StatusTypeDef HAL_FLASHEx_Erase( FLASH_EraseInitTypeDef *pEraseInit, uint32_t *PageError);'" />

`FLASH_EraseInitTypeDef`で指定したページまたはバンクを消去します。STM32G4でページを消去する場合は、消去種別、バンク、先頭ページ、ページ数を設定します。消去に失敗すると、`PageError`に対象ページが入ります。

<ApiSignature :signature="'HAL_StatusTypeDef HAL_FLASH_Program( uint32_t TypeProgram, uint32_t Address, uint64_t Data);'" />

指定した幅でデータを書き込みます。STM32G4の`FLASH_TYPEPROGRAM_DOUBLEWORD`は64ビット単位のため、アドレスを8バイト境界に合わせてください。先にページを消去し、データサイズを書き込み幅に合わせて順に書き込みます。

## 消去設定構造体

### `FLASH_EraseInitTypeDef` {#type-flash-eraseinittypedef}

消去方式、バンク、開始ページ、ページ数など、`HAL_FLASHEx_Erase()`へ渡す消去範囲を指定します。利用できるメンバと値は対象シリーズのHALヘッダで確認してください。

STM32G4でページ消去を行う場合、主に次のメンバーを指定します。

| メンバー | 内容 |
| --- | --- |
| `TypeErase` | ページ消去などの消去方式 |
| `Banks` | 対象バンク |
| `Page` | 最初に消去するページ番号 |
| `NbPages` | 連続して消去するページ数 |

ページ番号とアドレスの対応は、Flash容量とバンク構成で異なります。アドレスを決めるときは、リンカスクリプトのFLASH領域を分割し、プログラム領域と保存領域の境界を固定してから、その領域に含まれるページだけを消去します。

## 保存処理の基本手順

1. リンカ設定とメモリマップを確認し、保存領域をコード、定数、ブートローダーと重ねないでください。
2. 書き込むデータをRAM上で準備します。必要なら識別値やCRCなど、検証に使う情報も計算します。
3. `HAL_FLASH_Unlock()`を呼び、戻り値を確認します。
4. `HAL_FLASHEx_Erase()`で対象ページを消去します。
5. 消去に成功した場合だけ、アラインメントと幅を合わせて`HAL_FLASH_Program()`を呼びます。
6. すべての終了経路で`HAL_FLASH_Lock()`を呼び、各APIの戻り値を確認します。
7. 書き込んだ値を読み戻して検証し、問題がなければ設定に反映します。

## 注意事項

- 消去はページまたはバンク単位です。1つの値を更新するときも同じページの他のデータが消えるため、ページ全体の使い方を決めてください。
- 保存先をコードや定数の領域と重ねないでください。アドレスを固定する場合は、リンカスクリプトとMCUのFlash容量を照合します。
- 書き込みアドレス、幅、データ長を一致させてください。STM32G4のダブルワード書き込みでは、アドレスを8バイト境界に合わせます。
- 電源断や書き込み中のリセットに備え、magic値、バージョン、CRC、二重化などで破損を検出・復旧できるようにします。
- Flashの消去・書き込み回数には上限があります。頻繁に変わる値はRAM上でまとめて保存するか、別の記憶方式を選んでください。
- Flashの操作中に割り込みや別タスクが同じバンクを使う場合の制約を確認してください。
- 失敗時もFlashをロックしてください。早期returnが複数ある場合は、共通の終了処理を使うとロック漏れを防げます。
- STM32G4はページ消去・ダブルワード書き込みが基本となるが、別シリーズでは消去単位、プログラム幅、バンク選択、Option Byte APIが異なる。F4向けコードをG4へそのまま流用しない。
- 同一バンクの実行中に消去・書き込みすると、CPU停止や実行制約が生じる場合がある。割り込みベクタやRAM実行関数が必要か、対象シリーズのFlash章で確認する。
