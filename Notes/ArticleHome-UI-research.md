# 開発資料トップの改善（2026-10-22）

## 対象と目的

`Docs/Technical_articles/Article_Home.md`。既存のVitePress配色・書体を使い、初学者が読む順番を見つけることと、目的の記事を短い操作で探すことを優先する。公開URLへの反映・pushは今回未実施。

## 参考サイトの調査

2026-10-22に本文とブラウザ画面を確認。

| 参考 | 確認した構成 | 採用する部分 |
| --- | --- | --- |
| [Arduino Learn](https://docs.arduino.cc/learn/) | 分野ナビゲーションと、分野ごとの具体的な記事リンク。基礎・通信・電子回路を分ける | 分野と記事名を同時に見せる。入門分野の最初に基礎記事を置く |
| [MDN Web documentation](https://developer.mozilla.org/en-US/docs/Web) | ガイド・チュートリアル・リファレンスを役割別に整理。説明の近くにリンクを配置 | 記事探索とAPIリファレンスの入口を区別する |
| [Adafruit Learning System](https://learn.adafruit.com/) | Explore & Learn、初心者向け・プロジェクト・チュートリアルの入口と記事群 | 分野を知らない人の検索と、分野からの探索を併用する |

Adafruitの大型ビジュアルやArduinoの動画は、記事を探す目的への寄与が小さいため採用しない。

## 比較と設計判断

主軸はArduino Learnの分野別索引。既存サイトの白／ダーク背景、Noto Sans JP、ブランド色、細い区切り線を保持する。画像は使わず、具体的な記事名を見せる。

| 判断 | 根拠 | 実装 |
| --- | --- | --- |
| 大きな導入と集計パネルを縮小 | 改善前は最初の画面に記事名が見えない | ページ見出し、短い説明、検索へ集約 |
| 分野ごとの記事を直接掲載 | Arduinoの分野別索引 | 2列の分野一覧。小画面では1列。各分野の導入記事を最大3件掲載 |
| 検索を同一ページ内で実行 | 利用者の「欲しい情報へたどり着きたい」という依頼 | タイトル・説明・タグをAND検索。NFKC正規化、大小文字の差を吸収 |
| 分野とタグを組み合わせる | Adafruitの複数の探索入口と既存のタグ情報 | デスクトップの分野ナビ、小画面でも使えるselect、タグ絞り込み |
| API入口を別枠にする | MDNのガイド／リファレンス分離 | 見出し横に「関数・クラスを調べる」 |
| URLに状態を残す | 記事を読んで一覧に戻る動線 | q/category/tag/sort/viewを保存、再読込・戻るで復元 |
| 一覧に関連記事を追加しない | すでに記事を探すページなので内容が重複する | このページだけlayout: page |
| 全件を読む入口も残す | 分野別プレビューだけでは全記事を比較できない | 同じページで「すべての記事を見る」、分野順／タイトル順 |

新しいブランドデザインへの刷新ではなく、既存デザインに沿った直接実装を選択した。カード装飾中心の案より、分野・記事名・件数を近接させる索引を優先。

## 実装・確認の境界

- 変更対象は記事トップのコンポーネントとfrontmatter。共有検索・記事本文・生成カタログは直接編集しない。
- カタログの既存タグ対象を利用。一覧ページ5件を除外し、記事ディレクトリ内の資料を扱う。「制御ライブラリ」「有線通信の基本」は比較・選び方を含む資料のため残す。
- 本文全文検索はサイト共通検索を利用する。この画面の検索範囲を入力欄の直下に明記。
- 未分類の将来記事は「その他」、無線通信は対象資料がある場合だけ分野を表示。
- 現在のworkspaceは `dev`。旧devのcheckoutは `feat/dev-preserved-20261022` へ切り替え。元workspaceの未コミット変更は `.worktree/sensor-selection-preserved` の `feat/sensor-selection` に保存し、stashも保持。追跡ファイルはstashとのGit内容比較で一致、改行の自動変換を除く内容を保持。
- devの実データは41記事・5分野・26タグ。センサー選定記事がない場合は「制御ライブラリ」と表示し、存在しない内容を案内しない。

## スクリーンショットで修正した点

1. 初回：上部のタグ、一覧後の自動関連記事が重複。専用ページレイアウトに変更。
2. 初回：検索とselectの入力位置がずれる。ラベル下の間隔を統一。
3. 記事名の初期順が五十音主体。分野プレビューを基礎→環境→実践に調整。
4. 小画面：検索結果0件の次の操作が必要。解除ボタンと検索欄へのフォーカス復帰を確認。
5. 全記事に切り替える入口と、選択済みタグの解除を追加。
6. 320px幅の共通body最小幅による横スクロールを、記事トップだけの指定で解消。320px・768pxでscrollWidthとclientWidthが一致。
7. 掲載順データのない状態を踏まえ、並び替えを分野順／タイトル順に変更。解除時は並び順も初期化。
