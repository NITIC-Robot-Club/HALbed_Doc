# ツール一覧の改善（2026-10-22）

対象は `ToolsDirectory.vue`。`dev` の元workspaceで作業。先行する記事トップの書体・色・見出し寸法・区切り線を基準とする。

## 参考と採用方針

| 参考 | 確認内容 | 採用 |
| --- | --- | --- |
| [Omni Calculator: Physics](https://www.omnicalculator.com/physics) | Web取得した本文では分野ごとに計算機名と具体的な用途説明を並べる | 技術名だけでなく、どの量を求められるかを添える |
| [All About Circuits: Tools](https://www.allaboutcircuits.com/tools/) | Web取得した本文ではApplication Type別に分類する | 設定値・性能計算・単位変換を別分野にする |
| 今回改善した開発資料トップ | 同じサイトの見出し、余白、色、細線による情報階層 | 外観の主基準。新しいブランド表現や画像を足さず、既存UIと揃える |

外部サイトは本文調査を根拠とする。All About Circuitsの実ブラウザ表示はセキュリティ検証画面に止まり、Omniのブラウザ取得はタイムアウトしたため、外部サイトのスクリーンショット比較をしたとは扱わない。公開Tools_homeもWeb取得は失敗したため、リポジトリとlocalhostの実画面を実装・検証の基準とした。

## 決定

- 7件のため検索・ソートは設けず、3分野で全件を並べる。元の一覧に漏れていた既存のトルク計算・出力計算を追加。
- 各ツールを「名称→用途→入力→結果」の順に統一。分類2/3/2件を見出しの近くに表示する。
- 横に広い画面は3列、タブレットは2列、スマートフォンは1列。スマートフォンには分野へ直接進むリンクを置く。
- 計算画面へ進むリンクは項目全体を押せる。ホバー時も位置は動かさず、キーボードのフォーカスを表示。
- 入力と出力は選択に必要な代表項目。詳細なパラメーターは実際の計算画面で扱う。
- トルク変換の説明を実装のN·m / kgf·cm / kgf·m / lbf·ftへ修正。未対応のN·cmを削除。
- 変換画面のコピー機能を「換算値のコピーに対応」とし、一覧自体を押すとコピーされるような誤読を避ける。
- CANは既存エンジンがbxCANプロファイルを使う範囲を表示する。CAN FDモードも同じプロファイルを使う既存の計算仕様は今回変更していない。
