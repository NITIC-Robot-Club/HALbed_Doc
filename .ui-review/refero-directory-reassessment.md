## Reference lock / 決定台帳（実装前）

主方向は技術資料の索引。白い作業面、既存のサンセリフ、短いタイトル主体、少数の型に統一する。説明・カード・装飾ストライプは追加しない。既存の線画アイコンと6pxの操作部角丸は維持。写真やイラストを必要とする用途ではない。

| 決定 | 根拠と役割 |
|---|---|
| 記事・ツールのリンクを既存ブランド色に統一 | Python/MDNの索引。色は遷移可能な要素に使い、面装飾に拡張しない。 |
| hover/focusで下線 | MDN。文字の色だけに操作の識別を依存しない。 |
| 操作文言を14px、結果の分野/bxCANを13pxへ | Refero typography: 機能UIでは一つの書体、少数のサイズとウェイト。現在12pxの判断材料を読みやすくする。 |
| 項目行は52px以上、分野の開放構造を維持 | ユーザーの承認済み構造。情報量を増やして単調さを埋めない。 |
| popupを画面内へ収める | 独立監査と実測390x500: タグpopupのbottom549.8で49.8pxが画面外。上下の空きを使って配置。 |
| タイトル順を選んだら実際に全件を並び替える | 実測: タイトル順表示なのに結果0行/分野プレビュー5群のまま。操作と画面の対応を修正。 |

対象はArticleDiscoveryHome / ToolsDirectory / DirectorySelect。本文と計算ロジック、全記事・7ツールのリンクは維持。ツール一覧のタブレット2列は左右に同数の分野を置く目的で変更しない。構成の対称性だけを理由に1列へ増長しない。
