# 図版で確認すること

## 配線交差と機器の説明領域

- 共通信号と個別選択線の経路は、接続点だけでなく非接続の交差も確認する。
  → 情報欠落。線が重なると別の信号が短絡して見え、ラベルが読めても正しい配線を決められない。
  → 端子を機器枠の別位置へ分け、接続点は点、非接続は白抜きで示す。幹線を最後の分岐まで延ばしたかも確認する（Wired Communication / 2026-10）。

- SVGの推定高さだけでなく、Figmaの実フォントの文字境界を確認する。
  → 情報欠落。行高の数pxの差でグラフ最下段が切れる。
  → 原稿とFigmaの文字列・境界を突合し、図形のGND記号と注記の間にも余白を設ける（Wired Communication / 2026-10）。

## 曲線と説明を同時に読める配置

- 軸の下へ注記を置くとき、横軸ラベルも同じ場所を使っていないか確認する。
  → 情報欠落。ジャーク図で時間軸とインパルス注記が重なると、時間の単位と矢印の意味を読み分けられない。
  → 軸ラベルの下に独立した注記行を確保する（Low_Layer図版 / 2026-10）。

- 数式に使う略記を図や隣接本文で定義する。
  → 認知負荷。Rup/RdownとVIH,min/VIL,maxだけでは、初学者が抵抗の向きや入力しきい値を取り違え得る。
  → 図直下にプルアップ／プルダウンとHigh／Lowの保証しきい値を明記する（Low_Layer図版 / 2026-10）。
