# サイト共通デザインの見直し（2026-10-26）

事前コミット3312b1b（一覧の階層とフィルター修正）。以下はその後の未コミット変更。既存の生成カタログ説明差分・図版等は本作業と分けて保持。

## 基準と決定

Referoスキルのtypography/anti-ai-slop、前回のPython/MDN比較、ユーザーの実画面指摘を基準にする。Referoライブ検索は利用できない。装飾を一律に削るのではなく、操作・本文・結果の役割で形を使い分ける。

| 対象 | 決定と理由 |
|---|---|
| 色 | ヒーローだけのグラデーション、インディゴのテーマ色、別定義のtool-accentをブルーへ統合。リンク/選択/フォーカスの意味を共通化し、ダークのリンクは明るい青。 |
| トップ | 重複したHAL紹介と不要な英語eyebrowを除去。既存5入口の名前/リンクは維持。ユーザー指摘により、項目全体を押す入口は8px角丸の枠と本文色にする。詳細リンクの青文字/下線を一律に押し付けない。 |
| 操作部 | 入力/selectは6px角丸、46px以上、明確な境界とfocus outline。checkbox/radioへ数値入力用の枠を適用しない。 |
| 計算画面 | 共通ToolShellのタイトルをh1とし、同じ書体・階層へ。英語Calculator/Converterの重複ラベルを外し、一覧へ戻るリンクを全7画面で共有。 |
| 計算結果 | 主結果と同じ単位を再掲しない。トルクN·m、出力Wの換算行を除去。別単位への換算は維持。モバイルの結果は左揃え、不要な装飾ストライプと重複罫線を外す。 |
| API一覧 | h1を他の一覧と同じ大きさにする。英語eyebrow、カテゴリの冗長な説明を外す。16クラス名だけでは区別しづらい項目の短い用途は残す。 |
| 本文 | h2の自動罫線を外し、Markdownの明示的な区切りとの二重線を防ぐ。本文/コード/表の内容は変えない。 |
| ナビ | モバイルのMenu/Return to top、本文目次の英語ラベルを日本語へ。大分類や既存リンク先は維持。 |

## UI・文言の差分レビュー

| 操作/状態 | 判定・根拠 |
|---|---|
| トップ5入口 | 良: 5リンクを保持。モバイル1列の64px以上の項目全体を押せる。枠はこの操作単位にのみ使用。 |
| トップ初期説明 | 良: ヒーローの名称・主旨・2CTAは残し、次の同義説明を削除。 |
| API16入口 | 良: 16リンク確認。390pxでclientWidth=scrollWidth=375。短い用途でAPI同士を区別できる。 |
| 全7計算画面の見出し | 良: 各画面にh1が1つ。代表入力に6px角丸と枠が反映。 |
| 全7画面320px | 良: documentElementのscrollWidth/clientWidth一致を確認。 |
| 入力→結果 | 良: トルク半径20cm・力10Nで主結果2N·m。換算行はkgf·cm/kgf·m/lbf·ftの3行となりN·mを再掲しない。 |
| コピー | 既存のbuttonイベントと数値計算を維持。今回クリップボードへの実コピー検証はしていない。 |
| 計算画面から戻る | 共通アンカーを追加。7画面で同じhref。 |
| 本文の読み順 | 良: GPIO本文の見出し・コード・型リンクを実画面確認。既存の文章・型情報は保持。 |

全コンテンツの文章を改稿したものではなく、共通テーマと主要ページ型の見直し。FAQ等の既存本文の編集課題、実スクリーンリーダー、全コピー操作、全記事の手動通読は今回の対象外。計算ロジックと単位係数は変更なし。
