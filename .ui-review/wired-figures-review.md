# Wired Communication 図版の表示レビュー

2026-10-22。対象はFigmaの既存38フレーム（PC25、モバイル13）。図を開き、配線・送信順序・比較値を読み取る表示状態を対象とする。操作コントロールはない。公開サイトへの反映は今回の範囲外。

## 修正した問題

- 情報欠落：I²Cの1バイトとACKが対応しなかった。8データ＋9番目ACKを矩形波で揃え、START/STOPの例外も明記。
- 認知負荷：SPIの線が機器名に重なった。端子を上辺・底辺へ分離し、文字領域から配線を外した。
- 情報欠落：SPIの共通線やCSが交差点で短絡に見えた。接続点を点、非接続を白抜きで区別。デイジー最後のCS端子まで幹線を延長。
- 比較不能：CAN 8/64 byteの棒が同じ尺度でなかった。データ部のみを1:8の尺度で比較。
- 認知負荷：CANの役割説明の位置がずれた。コントローラのフレーム処理とトランシーバの差動変換を隣接表示。
- 情報欠落：CAN FDのRTR、調停のbit番号、Bus Off条件を訂正。
- 身体操作：モバイルで横長図の文字が縮む。400px幅で独立した縦配置を作成。
- 情報欠落：グラフの下部注記がFigmaの実フォントで切れた。高さを470pxへ増やし最終スクリーンショットで確認。
- 認知負荷：モバイルI²CのGND記号と説明が接近。注記を下げ510pxの高さを確保。

## 文言と検証範囲

文言の母数は540ノード。数値・信号名・短い説明を含む原稿とFigmaの全文字列を突合し一致を確認。信号名は規格上の英語を保持し、説明は日本語とした。TEC/RECとZ₀は図内で定義し、模式図・仮定電圧・データ部だけの比較を明記。原稿の全ラベルはcacheのscenes.jsonに保存する。

38図のローカルSVGプレビューを確認。Figmaでは全38図の寸法・全540文字ノード・フォント欠落・領域外・図同士の重なりを確認し、13代表図のスクリーンショットで実表示を確認。全38図の個別Figmaスクリーンショット確認までは実施していない。サイトは変更していないため今回はサイトビルド・PC/スマートフォンのサイト表示確認を行っていない。
